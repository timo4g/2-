# PsychoMod v5.0 — 100 расстройств

Fabric 1.20.1. Нужен JDK 17.

## Сборка
1. Установи JDK 17 и Gradle 8+
2. В папке проекта: `gradle build` (или `gradlew build` если добавишь wrapper)
3. Готовый jar: `build/libs/psychomod-5.0.0.jar`

## Установка
- **Сервер:** jar + Fabric API в `mods`
- **Клиент:** тот же jar + Fabric API (ради HUD, галлюцинаций и звука таблеток)

## Новое в v5.0
- **100 расстройств**: 75 исходных + 25 дополнительных диагнозов
- **Таблетка снимает ОДНО случайное расстройство** (не все сразу!)
- **Крафт: 1 таблетка** — алмаз сверху, ведро молока в центре, остальное стекло (7 шт)
- **Задания БЕЗ наград** — выполнение лишь отменяет штраф
- **Молоко не лечит** — блокируется, если есть хоть одно расстройство
- Задания появляются в случайное время: 5–20 минут (настраивается)

## Конфиг (config/psychomod.json)
- intervalMinutes — раз в сколько минут диагноз
- effectDurationMinutes — длительность эффектов
- whisperChance — шанс шёпота
- taskMinMinutes / taskMaxMinutes — диапазон появления заданий
- hallucinationsEnabled / tasksEnabled — выключатели механик

## Как лечиться
Только таблетка! Она лечит одно целое расстройство за раз. Расстройства и их эффекты не проходят сами. Повторно один диагноз не выдаётся, пока он активен. Молоко заблокировано, /effect clear остаётся у админов. При получении диагноза в чат выводится его описание эффектов на русском.
